# Franklin and Lamar profile

The initial profile is a full-flow **attempt**, with no observed successful autonomous Enhanced playthrough yet. The game starts the mission/replay; FiveVibe is explicitly armed by the player. There is no general mission solver, combat controller or campaign loop.

## Observations and actions

| Evidence | Decision |
| --- | --- |
| Running `armenian1` plus known protagonist | Attach to this mission only |
| Known objective label currently displayed | Remember its semantic goal |
| Persistent Lamar ped and opening walk | Walk nearby while the story progresses |
| `AR1_CHOOSE` and mission-owned `ninef2` / `rapidgt2` | Enter an available driver's seat |
| Driver seat plus Lamar's active recording / `AR1_CHASE` | Follow his route with physical inputs |
| `AR1_PARK` | Approach the parking point beside Lamar |
| `LOSE_WANTED` and positive wanted level | Drive away from police; wait while stars are greyed out |
| `AR1_GOGARAGE`, wanted level zero | Drive to the dealership's mission marker |
| Dealership phase, mission-owned Buffalo available | Enter Franklin's car, then wait for Lamar |
| `AR1_HOME` and passenger confirmed | Drive into the actual home arrival area |
| Scene / fade / disabled driving controls | Yield to GTA, retaining the goal |
| Positive `sp1_missions_passed` / `sp1_missions_failed` delta | Confirm result and stop |
| Script exit without counter evidence | Wait 30 seconds, then report unconfirmed |

The mission recording is **5, `mattarmenian`**. Positions are read from data already loaded by GTA; the mod does not start recorded playback on the player's car. A nearest-point follower chooses a lookahead target, then computes steering, throttle and braking from current orientation and speed. A route mismatch falls back to native vehicle following. No game route data is shipped in FiveVibe.

The dealership and home coordinates are profile-specific arrival references, cross-checked against nearby yellow mission blips. They are not generated by the language model. A short recovery reverses with normal controls; failure returns control instead of advancing the mission artificially.

## Source evidence and limits
